---

A parallel-jaw robot gripper needs to grasp '{grasp_object}'.

Manipulation task: "{grasp_hint}"

Mark the CONTACT REGION on '{grasp_object}' in THIS image --- the whole
surface patch the gripper's fingers close around and touch for a stable
grasp (the handle / grip body), NOT the functional tip or any part this
task should not touch (a bottle's cap, a hammer's striking head, a
kettle's spout, a knife's blade, etc.).

This is an AREA, not a point. The box must enclose the full span the
gripper's fingers would close across, along the object's own graspable
length, not a single corner or an arbitrarily tiny box. If '{grasp_object}'
has a distinct handle or narrow grip section, cover that section only —
not the whole object. If it has no distinct handle (a plain block, cup,
or box), cover a natural graspable area of its body instead.

Coordinates: normalized [y, x], each in the integer range [0, 1000].
[0, 0] = the center of the top-left pixel. [1000, 1000] = the center of
the bottom-right pixel. affordance_bbox is [y1, x1, y2, x2] with
y1 < y2 and x1 < x2 (top-left corner, then bottom-right corner).

If you CAN identify a contact region for '{grasp_object}' on this image
with reasonable confidence, set status="localized" and give:
  - affordance_description: a short phrase naming the region (e.g.
    "bottle body below the cap", "hammer handle").
  - affordance_point_yx_norm1000: [y, x], the region's own center.
  - affordance_bbox_yx_norm1000: [y1, x1, y2, x2] as defined above.

If '{grasp_object}' is not visible, too occluded to tell where its
graspable region actually is, or has no safely graspable region visible
in this image, set status="unavailable", affordance_description=null,
affordance_point_yx_norm1000=null, affordance_bbox_yx_norm1000=null, and
give at least one reason code. Do NOT invent a box to avoid returning
"unavailable" --- a wrong region is worse than a typed abstention, because
a downstream grasp planner cannot tell a guessed box from a real
observation.
  Use ONLY these reason codes, choosing every code that applies:
    TARGET_NOT_VISIBLE, OCCLUDED, OUT_OF_FRAME, UNCERTAIN_LOCALIZATION

Output ONLY this JSON object, no markdown fences, no other text:
{
  "status": "localized" | "unavailable",
  "affordance_description": "<short phrase>" | null,
  "affordance_point_yx_norm1000": [y, x] | null,
  "affordance_bbox_yx_norm1000": [y1, x1, y2, x2] | null,
  "reason_codes": ["..."]
}
